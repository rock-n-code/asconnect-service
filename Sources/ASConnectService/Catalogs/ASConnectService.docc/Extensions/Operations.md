# ``Operations``

API operations, with input and output types, generated from the paths section of the OpenAPI document.

## Overview

The ``Operations`` namespace contains a nested enum for each API operation defined in the App Store Connect API OpenAPI specification. Each operation enum encapsulates the `Input` and `Output` types for that specific endpoint.

Each operation typically provides:

- An **`Input`** struct containing the request `Path`, `Query`, `Headers`, and `Body` types
- An **`Output`** enum with cases for each possible HTTP response status code
- An **`id`** string constant with the operation identifier

These types are used by the ``APIProtocol`` methods and the ``Client`` implementation.
